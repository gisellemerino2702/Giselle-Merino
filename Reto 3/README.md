# Sistema de Análisis de Ventas por Producto

Este programa procesa registros de ventas desde la entrada estándar, calcula las unidades vendidas, el ingreso total y el precio promedio por producto.

## Funcionalidades

- Lectura de múltiples registros de ventas.
- Validación de datos inválidos.
- Cálculo automático de:
  - Unidades vendidas.
  - Ingreso total.
  - Precio promedio por unidad.
- Ordenamiento de productos por mayor ingreso generado.
