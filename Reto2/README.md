# Conversor y Clasificador de Temperaturas

Este programa lee datos de temperaturas desde la entrada estándar, convierte temperaturas en Fahrenheit a Celsius y clasifica cada temperatura según distintos rangos.

## Funcionalidades

- Conversión de Fahrenheit a Celsius.
- Clasificación automática de temperaturas.
- Validación de datos inválidos.
- Lectura de múltiples registros desde entrada estándar.

## Clasificación de temperaturas

| Rango en Celsius | Clasificación |
|---|---|
| Menor a 0°C | Congelado |
| 0°C a 15°C | Frío |
| 16°C a 25°C | Cálido |
| Mayor a 25°C | Extremo |
