# Sumador de Valores Separados por Comas

Este programa en Python lee líneas desde la entrada estándar, limpia caracteres inválidos y calcula la suma total de los valores numéricos separados por comas.

## Funcionalidades

- Lectura de datos desde teclado o archivos.
- Limpieza automática de caracteres no numéricos.
- Conversión segura de datos.
- Suma de números separados por comas.
- Manejo de errores y datos inválidos.
